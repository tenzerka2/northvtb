## Как запустить на компьютере

Нужны Docker с Compose, Python 3 и make. Клонировать репозиторий и выбрать ветку codex/north-foundation, затем из корня проекта выполнить `make demo`. На Apple Silicon: `DOCKER_DEFAULT_PLATFORM=linux/amd64 make demo`. Эмуляция может увеличить время запуска. Проверенная контейнерная цель — amd64; native arm64-сборка не подтверждена.

Скрипт создаёт локальные секреты, запускает базу и API, применяет миграции и выполняет HTTP-сценарий. API слушает только 127.0.0.1:8080 на хосте. Повторный `make demo` создаёт новый набор поручений и не требует удаления базы. Остановка — `docker compose down`; не использовать `down -v` для обычного перезапуска. Не показывать .env и содержимое .secrets на записи.

В среде подготовки материалов Docker и PostgreSQL отсутствуют. Поэтому нового локального сквозного прогона здесь не заявляем; доказательство — вышеуказанный настоящий CI. Ни один скриншот не изображает несуществующее локальное приложение.

## Последовательность будущей демонстрации

| Эпизод | Что показать | Фактический смысл |
| --- | --- | --- |
| Поручение | Товар, 85 000 ₽, новый, проверенный продавец, одна покупка, срок | Владелец утверждает ограниченные условия |
| Дорогое предложение | 96 900 ₽, отказ по сумме | Лимит проверяет backend |
| Непроверенный продавец | 81 000 ₽, отказ по условию продавца | Более низкая цена не снимает ограничения |
| Допустимая покупка | 82 990 ₽, разрешение, затем успех | Разрешение и платёж — разные этапы |
| Повтор | Попытка исполнить использованное разрешение | Второй платёж не создаётся |
| Подмена | Новое живое разрешение, изменение 82 990 на 92 990 ₽ | Тест именно привязки суммы, не просто повтор уже использованного разрешения |
| Возврат и история | Полный возврат, право покупки остаётся использованным | Деньги и полномочия имеют разные жизненные циклы |

Для короткого ролика достаточно первых пяти эпизодов, остальные — техническое приложение. Этот сценарий подготовлен как информация; видео не записано.
